# Contributing to prosecheck

Thank you for your interest in prosecheck.

prosecheck does not accept external pull requests at this time.
Do not open a pull request unless a maintainer requests one.

## Propose a contribution

Open a GitHub issue to:

- Report a problem
- Request a feature
- Suggest a documentation change
- Discuss another improvement

Search the open and closed issues before you create a new issue.
If an issue covers your proposal, add to that discussion.

Describe the problem and its effect.
If an example makes the problem easier to understand, add a short example.

A maintainer will review the issue and select the next action.
The maintainer can request more information or invite a pull request.
